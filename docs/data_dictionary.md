# Data dictionary

This file should describe the processed data files deposited on Figshare and used by the analysis scripts.

Recommended columns for each entry:

- file name
- file type
- figure/panel used
- rows represent
- key columns
- units
- notes

## Example entry

### processed_single_cell_organelle_features.csv

- Location: [Figshare DOI]
- Used for: Figs. 1-6 and supplementary analyses
- Rows: segmented cells
- Key columns: cell_id, mouse_id, condition, acinus_id, position, organelle feature columns
- Notes: Features were aggregated at the single-cell level after z-stack linking.
